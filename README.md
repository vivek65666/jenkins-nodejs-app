# Jenkins Node.js CI/CD Pipeline 🚀

This project demonstrates a simple CI/CD pipeline using Jenkins for a Node.js application. The pipeline automatically builds, tests (optional), and deploys the application whenever code is pushed to GitHub.

---

## 📌 Project Overview

- Node.js web application
- Automated CI/CD using Jenkins
- GitHub integration for source control
- PM2 for process management (production-ready deployment)

---

## ⚙️ Tech Stack

- Node.js
- Express.js
- Jenkins
- Git & GitHub
- PM2 (Process Manager)
- Linux / Windows environment

---

## 🚀 Features

- Automatic code checkout from GitHub
- Jenkins pipeline execution on every push
- Automated build process
- Application deployment using PM2
- Zero manual deployment effort
